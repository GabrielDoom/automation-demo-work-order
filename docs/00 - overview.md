# Automation Demo — Service Request Workflow

## Objective

Demonstrate the automation of a repetitive administrative workflow for a small service company.

## Business problem

Service requests arrive through unstructured channels and require manual transcription, document creation, status tracking and reporting.

## Transformation

Request → Structured record → Work order → Status tracking → Management report

## Success criterion

A new request must generate a structured record and work order automatically and become visible in the operational report.
