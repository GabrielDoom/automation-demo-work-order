## Functional Requirements

FR-01 Receive a service request.
FR-02 Assign a unique request ID.
FR-03 Store the request in a structured database.
FR-04 Generate a work-order document.
FR-05 Store the work order and its link.
FR-06 Allow status updates.
FR-07 Summarize operational status.

## Non-functional Requirements

NFR-01 Must run with minimal local computing resources.
NFR-02 Must require no dedicated server.
NFR-03 Must be understandable in a short commercial demonstration.
NFR-04 Must use fictional data only.
