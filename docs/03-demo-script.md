# Demo Script

## Objective

Demonstrate the complete administrative workflow in a few minutes.

## Scenario

A fictional customer requests technical maintenance from a small service company.

## Demonstration sequence

1. Open the service request form.
2. Submit a fictional request.
3. Open the operational spreadsheet.
4. Show that the request was registered automatically.
5. Show the automatically assigned request ID.
6. Open the generated work-order document.
7. Show the request data transferred into the document.
8. Change the request status from `Received` to `In Progress`.
9. Open the reporting sheet.
10. Show that the operational summary reflects the current workflow status.
11. Change the request to `Completed`.
12. Show the final report state.

## Value proposition demonstrated

The workflow removes repeated manual transcription between:

- incoming request;
- operational control;
- work-order creation;
- status tracking;
- reporting.

## Target demonstration time

3–5 minutes.
